# Profile — fuller reference

Not tracked by git: this is the private working document behind `master.yaml`.
Copy to `profile.md` and fill in. It is fed to the assistant as grounding, so
everything here should be true and specific.

## Contact & basics
Name, title, email, phone, location, links, driving licence.

## Location constraints
Where you live, how far the nearest cities are, how many days in an office you
would actually accept. The scoring uses this — see `searches.yaml`.

## Education
Each qualification, with the years and institution, plus how to describe it in
a form that expects a different country's system.

## Experience
Every role: dates, employer, what you actually built, the technologies. More
detail than fits on a CV, because the assistant selects from it.

## Projects
What each one does, what is genuinely finished, what is a prototype.

## Skills — honest levels
Split into what you have shipped with, what you have used, and what you have
only read about. Being candid here is what stops a cover letter overclaiming.

## Gaps
Things postings ask for that you do not have, and the nearest true thing you
could say instead.

## Salary and availability
Bands, notice period, earliest start.
